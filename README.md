# 🌍 Force-Directed Graph of Country Borders

This project visualizes a **force-directed graph** where each node represents a country, and the connections indicate shared borders. Each node displays the **flag of the corresponding country**, providing an engaging and intuitive view of the world’s geopolitical landscape.

## 🚀 Features

- Interactive visualization of countries and their shared borders.  
- Each node displays the respective country's flag.  
- Links between nodes represent land borders.  
- Zoom and drag to explore the graph.  
- Built using web technologies (D3.js + HTML/CSS/JS).
